# 🚀 Workscript

> A fast and flexible DAG executor written in Go with support for dependencies and concurrent task executions.

---

## 📦 Features
- ⚡ Concurrent execution of tasks
- 🧱 Declarative dependency graph (`before` / `after` edges)
- 🔧 Configurable run/post modes
- 📚 Clear logging and status tracking

---

## 🛠️ Getting Started

### ✅ Prerequisites
